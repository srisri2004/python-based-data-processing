# Python-Based Data Processing Utilities

A Python-based data processing project that automates **data cleansing, file validation, JSON/XML processing, log analysis, and file processing** using OOP and generators.

## Features

- Data cleaning and validation
- CSV, JSON, and XML processing
- Log file analysis
- Automated file processing
- OOP-based design
- Generators for memory-efficient processing
- Exception handling

## Technologies

- Python
- OOP
- JSON / XML / CSV
- Regular Expressions
- Git & GitHub
